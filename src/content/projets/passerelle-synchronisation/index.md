Application intermédiaire consommant les API de deux plateformes de tracking pour comparer les données, détecter les écarts et synchroniser les informations dans les deux sens.

Le cœur du sujet : deux systèmes tiers, deux formats, aucun contrôle sur leurs évolutions. La difficulté n'est pas d'appeler une API, c'est de gérer les désynchronisations, les échecs partiels et les changements de contrat côté fournisseur sans corrompre les données.

Intervention de 2 ans, en régie et en relation directe avec le client. Secteur du service de sous-traitance. Application interne, non accessible publiquement.
